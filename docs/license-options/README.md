# Software license options

The active software license is [the repository LICENSE](../../LICENSE):
the official PolyForm Noncommercial 1.0.0 text, unchanged, preceded by a
project-specific application/scope notice. The exact standard text is also
provided as [an attachment-ready file](POLYFORM-NONCOMMERCIAL-1.0.0.txt).

The [academic research software license](ACADEMIC-SOFTWARE-LICENSE.draft.txt)
is a **custom, AI-assisted, unadopted draft** for institutional/legal review.
It is not the standard TurboGAP/Cambridge ASL and does not provide an
alternative license grant for current software. It proposes reciprocal
source distribution and narrower academic-research eligibility, expressly
excluding work intended to support commercial products/services. Review
these restrictions and compatibility before considering adoption.

PolyForm has broader permissions: its Noncommercial Organizations clause
explicitly permits use by educational institutions and public research
organizations, among others, regardless of funding or resulting obligations.
Do not describe the standard license as blocking all industry-funded
university research. Changing those clauses would create a different custom
license, not the official PolyForm Noncommercial 1.0.0.

Both options are source-available, not OSI-approved open-source licenses.
Neither can remove valid prior MIT grants or third-party rights. Actual
authority to relicense all contributions requires rights-holder review.
Models and datasets retain separate terms. The fine-tuned SloBERTa release has
NC permission from the SloBERTa owners, confirmed on 17 September 2026; the
original upstream model retains its CC BY-SA 4.0 license.

References: [official PolyForm](https://polyformproject.org/licenses/noncommercial/1.0.0)
and [TurboGAP ASL, for comparison](https://turbogap.fi/wiki/index.php/Academic_Software_Licence).
